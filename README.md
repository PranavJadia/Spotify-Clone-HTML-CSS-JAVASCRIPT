# Spotify Web Player Clone 🎧

This project is a front-end clone of the Spotify Web Player interface. Built with HTML, CSS, and JavaScript, it features dynamic album loading, song playback, and basic player controls—all styled to resemble the original Spotify experience.

## Features

- Fetch and display music albums dynamically
- Play, pause, skip, and navigate songs
- Real-time progress bar and time updates
- Volume control and mute functionality
- Responsive UI with sidebar and top navigation
- Albums loaded from folder structure and metadata

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API

## How to Run

1. Clone the repository.
2. Serve the project using a local server (e.g., VSCode Live Server, Python `http.server`, etc.).
3. Open `index.html` in your browser.
4. Make sure to preserve the folder structure for proper functionality.

> **Note:** This is a static front-end demo and does not include real-time streaming or Spotify APIs.
